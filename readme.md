# repositoriotest

Proyecto base muy simple en HTML.

## Descripcion

Este repositorio contiene una pagina estatica minima con un titulo principal.

## Estructura

- `index.html`: pagina principal del proyecto.
- `readme.md`: documentacion del proyecto.

## Como ejecutarlo

No requiere dependencias ni instalacion.

1. Abre `index.html` en tu navegador.
2. Alternativamente, usa un servidor local si prefieres:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
